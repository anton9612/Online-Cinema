Для установки и запуска необходимо следовать следующим пунктам:
- Скачайте проект на компьютер
- Перейдите в папку через cd Online-Cinema
- Выполните python -m venv venv
- активируйте окружение venv\Scripts\activate
- установите все нужные библиотеки через pip install -r requirements.txt
- запустите сервер командой python manage.py runserver
- откройте полученный адрес в браузере
- вы открыли сайт!
